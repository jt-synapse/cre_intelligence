# CRE Intelligence and Powered Land implementation plan

**Goal** — A field researcher can select cited parcels, investigate an owner, assemble a site, screen it, and carry the same site into a CRE opportunity and a reviewed dossier.

**Architecture** — Extend the existing FastAPI application, PostgreSQL/PostGIS database, database-backed worker and Next.js/MapLibre workspace. The first product milestone is a phone workflow on permitted data. Gwinnett qualification has its own evidence and release decision.

**Tech stack** — Python 3.12 in CI, uv, FastAPI/Pydantic, SQLAlchemy/psycopg, Alembic, PostGIS, private local/S3 storage, Node 24 in CI, npm, TypeScript and Playwright.

**Specification** — The upstream document defines the feature IDs, measurement rules, typed payloads, test examples and release gates. Use its sections 2, 4–9 and 12 alongside this plan. **Choice of first milestone.** Prioritizing live Gwinnett would concentrate effort on the four-match gap and permissions while the field workflow waits. ## Global constraints

- Preserve county-qualified identifiers, raw values, dated source records, co-ownership, unresolved evidence and historical versions. Keep canonical property grouping under global curation. Tenant-owned proposals use their own records.
- Reuse OIDC/PKCE, validated membership, transaction-local subject and organization, forced RLS, separate runtime/worker/operator grants, and current source-visible views. Recheck current rights on reads, retries, cached results, exports and downloads.
- Keep source acquisition, retention, display, offline cache, export, automated access and external AI use individually authorized. Introduce new manifest permissions with restrictive defaults for old JSON. Keep private artifacts and row-level benchmark evidence in the operator workspace.
- Use accepted full-resolution geometry, declared CRS, units, policy and dataset versions for calculations. Use deterministic spatial, matching, ranking and Decimal finance logic. Distinguish coverage gaps, conflicts and genuinely observed absence.
- Keep paid research opt-in on the worker, with budgets and document permission checks. Research, draft approval and external dispatch are separate actions. Use a fake delivery provider in automated verification.

## Phone workflow build record · November 24, 2026
